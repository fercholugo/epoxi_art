## Decisiones Tomadas

1. **Next.js 16 en lugar de 14**: npm install next@latest instaló v16.1.7. Es compatible con App Router del SPEC y más seguro (v14.2.29 tenía CVE).
2. **--legacy-peer-deps en Dockerfile**: Necesario por conflictos de peer deps entre eslint-config-next y otras deps.
3. **Imágenes procedurales en Gallery**: Canvas con gradientes en lugar de fotos reales hasta Fase 5 (CMS de galería).
4. **clsx + tailwind-merge**: Instalados tanto en host como en container (el volumen anónimo preserva node_modules del build anterior).
5. **useImageAnalysis.ts**: Hook completo escrito en Fase 2 aunque el backend del análisis se conecta en Fase 3. La UI de AIAnalyzer.tsx ya hace la llamada real a `/api/v1/analyze`.
6. **Confirmación del usuario**: El usuario confirmó Fase 1 y Fase 2 como superadas. Pidió checkpoint antes de continuar.

## Problemas / Bloqueos

- **Warning `version` obsoleto en docker-compose.yml**: Aparece en cada comando docker compose. No bloquea nada, es solo un warning. Se puede quitar el campo `version: "3.9"` del yaml.
- **Volumen anónimo node_modules**: Cada vez que se agreguen paquetes npm, hay que hacer `docker compose exec frontend npm install <pkg> --legacy-peer-deps` además del rebuild, porque el volumen anónimo no se actualiza automáticamente con el rebuild.
