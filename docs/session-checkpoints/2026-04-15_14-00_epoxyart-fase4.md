## Decisiones Tomadas

1. **BackgroundTasks en lugar de Celery**: Para emails se usa FastAPI `BackgroundTasks` — elimina la complejidad de un worker Celery separado. Suficiente para validar el negocio.
2. **Camelcase en schemas Pydantic**: Los campos del QuoteCreate usan camelCase (`tipoSuperficie`, `areaM2`, `tipoAcabado`) para coincidir exactamente con lo que envía el frontend sin necesidad de alias.
3. **Precio calculado server-side**: El backend recalcula el precio independientemente del valor que pueda enviar el cliente.
4. **Fallback de email en dev**: Si `SMTP_USER` está vacío, el servicio solo loguea el contenido del email sin fallar.
5. **Fase 3 pospuesta**: El usuario decidió saltar a Fase 4 para validar el alcance antes de invertir en la integración con Anthropic API.
6. **`docker compose up -d --force-recreate backend`**: Necesario cuando se cambian variables en `.env` — `docker compose restart` NO re-lee el `env_file`.
